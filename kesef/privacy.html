מדיניות פרטיות — הכסף שלי

עודכן: 8 באוקטובר 2026

  • "הכסף שלי" הוא כלי אישי של משק בית אחד, שרץ על מחשב פרטי. אין לו משתמשים מבחוץ.
  • הגישה לגוגל דרייב היא בהרשאה drive.file בלבד: הכלי יכול לראות ולערוך רק קבצים שהוא עצמו יצר. אין לו גישה לשאר הקבצים בדרייב.
  • הכלי משתמש בגישה הזו רק כדי להעלות עותקים של מסמכים (כמו תלושי שכר) לתיקייה בדרייב של בעל החשבון.
  • שום מידע מגוגל לא נמכר, לא מועבר לצד שלישי ולא משמש לפרסום. אסימון הגישה נשמר רק במחשב הפרטי.
  • אפשר לבטל את הגישה בכל רגע בכתובת myaccount.google.com/permissions.

Privacy policy — Kesef

  • Kesef is a personal tool for a single household, running on a private computer. It has no outside users.
  • Google Drive access uses the drive.file scope only: the tool can see and edit only files it created itself, and has no access to any other files in Drive.
  • This access is used solely to upload copies of documents (such as payslips) to a folder in the account owner's own Drive.
  • No Google user data is sold, shared with third parties, or used for advertising. The access token is stored only on the private computer. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
  • Access can be revoked at any time at myaccount.google.com/permissions.
